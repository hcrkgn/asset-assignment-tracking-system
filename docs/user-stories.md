# User Stories

## Admin

1. As an admin, I want to manage user accounts, because I need to control who can access the system.

2. As an admin, I want to assign roles to users, because different users need different permissions.

3. As an admin, I want to manage system categories, because assets need to be organized correctly.

4. As an admin, I want to view system activities, because I need to monitor important operations.

## Warehouse Officer

1. As a warehouse officer, I want to create a new asset record, because I need to track newly added assets in the system.

2. As a warehouse officer, I want to track asset quantities, because I need to know available stock levels.

3. As a warehouse officer, I want to record returned assets, because I need to update asset availability.

4. As a warehouse officer, I want to perform inventory counting, because I need to compare physical inventory with system records.

5. As a warehouse officer, I want to record maintenance activities, because I need to track repair history of assets.

6. As a warehouse officer, I want to search and filter assets, because I need to quickly find specific assets.

## Department Manager

1. As a department manager, I want to view assets assigned to my department, because I need to monitor department resources.

2. As a department manager, I want to request assets, because my department may need additional resources.

3. As a department manager, I want to approve asset assignments, because I need control over assets used by my team.

## Employee

1. As an employee, I want to view my assigned assets, because I need to know which assets are under my responsibility.

2. As an employee, I want to report damaged assets, because maintenance actions need to be started.

3. As an employee, I want to see my asset history, because I need to track previous assignments.
